# Agent 基础

Agent = LLM + 工具 + 循环 + 状态 + 环境。LLM 本身没有手脚：它只能根据输入的文字预测下一段文字，没有记忆、不会执行、也不知道时间。要让 LLM 变成能干活的 Agent，需要四个零件：

1. 工具（Tools）：把 Python 函数登记成菜单，模型输出结构化"工单"表示想调用哪个函数；真正执行工单的是宿主程序的 Python，不是模型。
2. 循环（Loop）：模型开单 → 代码执行 → 结果塞回对话档案 → 模型再决策，直到模型不再开单。
3. 保险丝：max_steps 限制最大循环轮数，防止程序失控烧钱。
4. 反馈（Execution Feedback）：工具结果必须回到对话档案里，模型才"看得见"执行结果；报错信息也是宝贵的反馈——模型读 stderr 就能自己修复代码错误。

好的任务环境有四个特征：可执行、可观察、可反馈、可验证。代码任务是 Agent 的主场，因为代码有解释器当裁判：退出码 0 表示成功，非 0 表示失败，stderr 说明失败原因。写诗任务则很难自动验证——没有解释器可以当阅卷老师。
